# ShowCab — UX Research & Product Design Case Study

## Overview

ShowCab is a UX research and product design project that explores an integrated platform for event discovery, ticket booking, and transportation planning. The project focuses on simplifying the fragmented workflow users experience when attending live events.

---

## Problem

Users attending events often rely on multiple platforms to:

• discover events
• purchase tickets
• arrange transportation

This fragmented workflow leads to confusion, time consumption, and logistical challenges.

---

## Research Methods

To understand user behavior and identify usability issues, we conducted:

• **Google Forms survey with 43 participants**
• User journey analysis
• Persona development
• Scenario-based design exploration

The research helped uncover how users currently plan events and the difficulties they face while coordinating tickets and transportation.

---

## Key Research Insights

Analysis of survey responses and feedback revealed several recurring patterns:

**1. Fragmented booking workflow**
Users frequently rely on multiple platforms for discovering events, purchasing tickets, and arranging transportation.

**2. Transportation uncertainty**
Many users struggle to find reliable transportation after securing event tickets, particularly during high-demand events.

**3. Timing coordination issues**
Users often worry about synchronizing event schedules with transportation availability.

These insights guided the design of ShowCab as a unified platform integrating event booking and transportation.

---

## Solution

ShowCab integrates event discovery, ticket booking, and transportation planning into one streamlined experience.

Key features include:

• event discovery and ticket booking
• integrated cab booking to event venues
• real-time notifications and updates
• simplified event planning workflow

---

## UX Artifacts

The UX design process included:

• User personas representing different event attendees
• User scenarios and journey flows
• Low-fidelity wireframes
• High-fidelity mobile prototypes

---

## User Testing & Evaluation

User testing revealed strong usability and satisfaction scores:

• **Login success rate:** 4.58 / 5
• **Sign-up success rate:** 4.48 / 5
• **Transport & profile pages usability:** 4.61 / 5

Users reported a positive experience with the platform and found the workflow intuitive and efficient.
